PENYELESAIAN LENGKAP

Soal: Gambarkan hubungan ER dengan FSA pada ER di bawah ini:
  1. ER = ab*cc
  2. ER = 01*1 ∪ 001
  3. ER = a* ∪ b*

A. Ekspresi Reguler: ab*cc

1. Analisis Ekspresi Reguler

ER = ab*cc
Interpretasi:
Ekspresi reguler ab*cc dapat dipecah menjadi komponen-komponen:
  • a : tepat satu karakter 'a'
  • b* : nol atau lebih karakter 'b' (Kleene closure)
  • cc : tepat dua karakter 'c' berurutan

2. String yang Diterima

Contoh string yang diterima:
  • acc (a diikuti 0 buah b, lalu cc)
  • abcc (a diikuti 1 buah b, lalu cc)
  • abbcc (a diikuti 2 buah b, lalu cc)
  • abbbcc (a diikuti 3 buah b, lalu cc)
  • dan seterusnya...
String yang ditolak:
  • bcc (tidak dimulai dengan a)
  • ac (hanya ada satu c)
  • abbc (hanya ada satu c di akhir)
  • aacc (ada dua a)

3. Diagram Finite State Automata

4. Tabel Transisi

State Input 'a' Input 'b' Input 'c' Keterangan
→q₀ q₁ - - State awal
q₁ - q₁ q₂ Menerima b* dan transisi ke c
q₂ - - q₃ Menerima c pertama
q₃ - - q₄ Menerima c kedua
*q₄ - - - State akhir (final)

5. Penjelasan Konstruksi FSA

Langkah-langkah konstruksi:
  1. State q₀: State awal yang menunggu input 'a'
  2. State q₁: State setelah menerima 'a', dapat menerima 0 atau lebih 'b' (self-loop)
  3. State q₂: State setelah menerima 'c' pertama dari q₁
  4. State q₃: State transisi untuk 'c' kedua
  5. State q₄: State akhir setelah menerima string yang sesuai pola ab*cc

B. Ekspresi Reguler: 01*1 ∪ 001

1. Analisis Ekspresi Reguler

ER = 01*1 ∪ 001
Interpretasi:
Ekspresi ini merupakan union (∪) dari dua pola:
  • 01*1 : '0' diikuti nol atau lebih '1', diakhiri dengan '1' (minimal satu '1')
  • 001 : tepat string '001'
Catatan Penting:
Operator ∪ (union) berarti FSA menerima string yang memenuhi SALAH SATU dari kedua pola. Ini memerlukan konstruksi NFA (Non-deterministic Finite Automata) dengan dua jalur.

2. String yang Diterima

String yang diterima dari pola 01*1:
  • 01 (0 diikuti 1 buah 1)
  • 011 (0 diikuti 2 buah 1)
  • 0111 (0 diikuti 3 buah 1)
  • 01111, 011111, dst.
String yang diterima dari pola 001:
  • 001 (tepat string ini)
Total string yang diterima: {001, 01, 011, 0111, 01111, ...} String yang ditolak:
  • 0 (tidak ada 1 di akhir)
  • 00 (tidak sesuai pola manapun)
  • 0001 (lebih dari 001)
  • 10 (tidak dimulai dengan 0)

3. Diagram Finite State Automata (NFA)

4. Tabel Transisi NFA

State Input '0' Input '1' Keterangan
→q₀ q₁ - State awal
q₁ q₄ q₂ Percabangan: jalur atas (1) atau bawah (0)
q₂ - q₂, q₃ Self-loop untuk 1* dan transisi ke final
*q₃ - - Final state untuk 01*1
q₄ - q₅ Menerima '1' terakhir dari 001
*q₅ - - Final state untuk 001

5. Penjelasan Konstruksi NFA

Karakteristik NFA:
  • Non-deterministic: dari q₁ ada dua kemungkinan transisi (ke q₂ atau q₄)
  • Jalur atas (q₀→q₁→q₂→q₃) untuk pola 01*1
  • Jalur bawah (q₀→q₁→q₄→q₅) untuk pola 001
  • State q₂ memiliki transisi ganda dengan input '1' (ke q₂ dan q₃)

C. Ekspresi Reguler: a* ∪ b*

1. Analisis Ekspresi Reguler

ER = a* ∪ b*
Interpretasi:
Ekspresi ini menerima:
  • a* : nol atau lebih karakter 'a' (termasuk ε)
  • b* : nol atau lebih karakter 'b' (termasuk ε)
Penting: Karena kedua pola mengandung Kleene closure (*), string kosong (ε) diterima oleh kedua pola. Oleh karena itu, state awal juga merupakan state akhir.

2. String yang Diterima

String yang diterima:
  • ε (string kosong)
  • a, aa, aaa, aaaa, ... (hanya a)
  • b, bb, bbb, bbbb, ... (hanya b)
String yang ditolak:
  • ab (campuran a dan b)
  • ba (campuran b dan a)
  • aba, bab, aabb, dll. (kombinasi a dan b)
Catatan: FSA ini TIDAK menerima string yang mengandung campuran 'a' dan 'b'. Hanya string yang terdiri dari semua 'a' ATAU semua 'b' (atau string kosong).

3. Diagram Finite State Automata (NFA-ε)

4. Tabel Transisi NFA-ε

State Input 'a' Input 'b' Input 'ε' Keterangan
→*q₀ - - {q₁, q₂} State awal & final (menerima ε)
*q₁ q₁ - - Final state untuk a*
*q₂ - q₂ - Final state untuk b*

5. Penjelasan Konstruksi NFA-ε

Karakteristik khusus:
  1. Transisi Epsilon (ε): Memungkinkan perpindahan state tanpa membaca input
  2. q₀ sebagai Final State: Karena a* dan b* keduanya menerima string kosong
  3. Percabangan dengan ε: Dari q₀, bisa langsung ke q₁ atau q₂ tanpa input
  4. Self-loop: q₁ untuk menerima multiple 'a', q₂ untuk multiple 'b'
  5. Isolasi pola: Setelah memilih jalur (a* atau b*), tidak bisa berpindah

RINGKASAN DAN KESIMPULAN

Notasi yang Digunakan dalam FSA

Simbol Keterangan Contoh
→ State awal (initial state) →q₀
* State akhir (final/accepting state) *q₄
Lingkaran ganda State akhir dalam diagram ◎
ε Transisi kosong (epsilon transition) Perpindahan tanpa membaca input
Self-loop Transisi ke state yang sama q₁ → q₁

Perbandingan Ketiga Ekspresi Reguler

ER Tipe FSA Jumlah State Karakteristik Khusus
ab*cc DFA 5 Deterministik, satu jalur linear dengan self-loop
01*1 ∪ 001 NFA 6 Non-deterministik, dua jalur alternatif
a* ∪ b* NFA-ε 3 Menggunakan transisi epsilon, state awal adalah final

Konsep-Konsep Penting

1. Kleene Closure (*)

Operator * menunjukkan pengulangan nol atau lebih kali. Contoh:

  • b* = {ε, b, bb, bbb, ...}
  • a* = {ε, a, aa, aaa, ...}

Catatan: Kleene closure SELALU menerima string kosong (ε)

2. Union (∪)

Operator ∪ menggabungkan dua ekspresi reguler, menerima string yang memenuhi SALAH SATU pola:

  • L(ER₁ ∪ ER₂) = L(ER₁) ∪ L(ER₂)
  • Biasanya memerlukan konstruksi NFA dengan percabangan

3. DFA vs NFA vs NFA-ε

  • DFA (Deterministic FA): Setiap state memiliki tepat satu transisi untuk setiap input
  • NFA (Non-deterministic FA): State dapat memiliki multiple transisi untuk input yang sama
  • NFA-ε: NFA dengan transisi epsilon (perpindahan tanpa membaca input)

Langkah Umum Konversi ER ke FSA

  1. Analisis Struktur ER:
    • Identifikasi operator (*, ∪, konkatenasi)
    • Pecah menjadi sub-ekspresi
  2. Tentukan Tipe FSA:
    • ER sederhana → DFA
    • ER dengan union → NFA
    • ER kompleks dengan banyak * → NFA-ε
  3. Konstruksi State:
    • State awal untuk memulai
    • State transisi untuk setiap komponen
    • State akhir untuk menerima string
  4. Tambahkan Transisi:
    • Self-loop untuk Kleene closure
    • Percabangan untuk union
    • ε-transisi jika diperlukan
  5. Verifikasi:
    • Test dengan string yang seharusnya diterima
    • Test dengan string yang seharusnya ditolak

Tips Penting

  • Self-loop: Gunakan untuk implementasi Kleene closure (*)
  • State Final: Jika ER menerima ε, state awal harus juga final
  • Percabangan: Union (∪) biasanya memerlukan percabangan dari state awal
  • Minimisasi: DFA dapat diminimisasi, NFA tidak selalu
  • Konversi: NFA dapat dikonversi ke DFA menggunakan subset construction
Kesimpulan Akhir:
Hubungan antara Ekspresi Reguler dan Finite State Automata adalah fundamental dalam teori komputasi. Setiap ER dapat direpresentasikan sebagai FSA, dan sebaliknya. Pemahaman tentang konversi ini penting untuk desain compiler, pattern matching, dan berbagai aplikasi dalam computer science.
